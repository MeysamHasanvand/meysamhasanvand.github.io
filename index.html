معماری و دامنه‌های تخصصی

فعالیت من معطوف به پیاده‌سازی زیرساخت‌های تاب‌آور، خودکارسازی سرویس‌های اداری و پیاده‌سازی معماری‌های وب مقیاس‌پذیر در ابعاد کشوری است. از مدیریت کلاسترهای دیتاسنتری HP و مجازی‌سازی VMware تا طراحی و امنیت سامانه ارجاع کارشناسان و مدیریت شبکه پورتال کانون‌های استانی، تمرکز بر دسترس‌پذیری ۹۹.۹٪، کاهش مخاطرات نفوذ و پایداری گردش داده است.

زیرساخت و مجازی‌سازی دیتاسنتر

پیکربندی سرورهای Enterprise HP ProLiant، مجازی‌سازی با VMware ESXi / vCenter، ریدبندی ذخیره‌سازها، و پیاده‌سازی متدولوژی‌های پشتیبان‌گیری Disaster Recovery با نرم‌افزار Veeam Backup.

HP ProLiant VMware ESXi Veeam Backup Windows Server Active Directory

امنیت شبکه و سرویس‌های ارتباطی

سخت‌سازی امنیتی فایروال‌های سخت‌افزاری FortiGate، روتینگ و سوئیچینگ سیسکو/میکروتیک، مدیریت پهنای باند، مانیتورینگ متمرکز PRTG و پیاده‌سازی مراکز تلفنی ویپ سازمانی با Issabel VoIP.

FortiGate FW MikroTik RouterOS Issabel VoIP PRTG Monitor Wireshark

دواپس، کانتینرها و توسعه نرم‌افزار

استقرار سرویس‌ها مبتنی بر Docker و Docker Compose، مدیریت پایگاه‌های داده SQL Server و MySQL، کشینگ با Redis، پیاده‌سازی لاجیک‌های بک‌اند .NET Core و اسکریپت‌های PHP و لینوکس (LPIC-1).

Docker Compose Linux / LPIC-1 .NET Core SQL Server / MySQL Redis

معماری پورتال‌های وب و سئو تکنیکال

معماری سیستم‌های مدیریت محتوا مبتنی بر وردپرس اختصاصی، پیاده‌سازی پروتکل‌های امنیت وب، بهینه‌سازی سرعت Core Web Vitals و ردگیری پیشرفته داده‌ها با Google Analytics، GTM و Search Console.

WordPress Core Technical SEO GTM & GA4 DNS Management Odoo ERP

پروژه کلان: معماری و طراحی پرتال وب کانون‌های استانی (۳۱ استان)

طراحی، استانداردسازی ساختار و توسعه وب‌سایت‌های کانون‌های کارشناسان رسمی دادگستری در ۳۱ استان کشور. این طرح شامل ایجاد یک دیزاین‌سیستم یکپارچه سازمانی، تفکیک دیتابیس‌ها و دسترسی‌های اداری استانی، هماهنگی با الزامات هویتی شورای عالی (HCIOE)، پیاده‌سازی پروتکل‌های امنیتی، ارتباط با وب‌سرویس‌های استعلام صلاحیت کارشناسان، و استقرار سامانه‌های اطلاع‌رسانی بومی با زمان پاسخ‌دهی استاندارد در سراسر کشور است.
